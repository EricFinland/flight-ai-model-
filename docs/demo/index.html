Put the two models side by side

Two small language models trained on books printed before 1903. One never read a word about balloons, airships, parachutes or flying machines; its twin read the same books with them left in. Both run here, on your own machine.

Read this first. These are tiny models (8.5 million parameters). Both write grammatical-looking nonsense, and across all 171 flight sentence pairs the difference between them is within the noise. Single sentences can differ a lot, but so do sentences with no flight in them at all.

I. Surprisal

Which ending is more surprising?

Give a sentence and two ways to end it. Each model scores both endings: the summed log-probability of the ending’s tokens after the sentence, the same computation as the project’s Python evaluation. The bars show how much more likely each model finds one ending than the other. The factor compares the two models: how many times more surprised the flight-free model is by ending A, relative to ending B, than the control is.

      What this does and doesn’t show

      • Tiny models. 8.5 million parameters and 13.9 million training tokens each, trained on a CPU. Neither beats chance on general 19th-century knowledge questions, and both write fluent-looking nonsense.
      • The overall effect is within the noise. Over 171 flight pairs the flight-free model is, on average, 1.42× more surprised by the flight wording, but the 95% interval runs from 0.52× to 3.51×, and the pre-registered test against non-flight pairs is null (p 0.345).
      • Single items swing wildly. “Parachute / umbrella” gives 5.89× and the aeronaut pairs average about 17×, but pairs with no flight in them (“lifeboat / locomotive”) reach 132×, and some flight pairs go hard the other way. One sentence is an anecdote, not evidence.
      • The control barely read about flight either: about 50 “balloons” in the text it actually trained on. The pipeline is built to rerun at 125M–1B parameters, where the comparison becomes meaningful.
