# Red-team patterns for the flight scrub audit (scripts/audit_leaks.py).
#
# Format: one pattern per line, "name :: regex". Lines starting with "#" are
# comments; blank lines are ignored. Patterns are Python regexes, matched
# case-insensitively against each paragraph AFTER prewright.flight.normalize()
# (accents folded, hyphenated line breaks re-joined, whitespace collapsed to
# single spaces). Keep them free of lookarounds and backreferences so that
# the fast ripgrep pre-screen (--rg) can run them too.
#
# Group tags in the name prefix:
#   lex_   things the lexicon should already catch (sanity: expect ~0 in main)
#   rt_    red-team terms the lexicon may MISS (expect some in main; judge them)
#   idea_  the IDEA of human flight without technical vocabulary
#   noise_ high-volume, mostly innocent; counted for comparison only
#   mod_   post-1903 / modern leakage (not flight)
