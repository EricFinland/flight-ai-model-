# Red-team patterns for the flight scrub audit (scripts/audit_leaks.py).
#
# Format: one pattern per line:
#     name :: regex :: anchor1|anchor2|...
# Lines starting with "#" are comments; blank lines are ignored.
#
# * regex: a Python regex, matched case-insensitively against each paragraph
#   AFTER prewright.flight.normalize() (accents folded, hyphenated line breaks
#   re-joined, whitespace collapsed to single spaces).
# * anchors: lowercase literals; every match of the regex must contain at least
#   one of them (as a substring of the lowercased, normalised paragraph). The
#   auditor only runs a regex on paragraphs that contain one of its anchors, and
#   in --rg mode ripgrep pre-screens the corpus for the union of all anchors (a
#   space in an anchor also matches a raw line break). Too-short anchors cost
#   speed, never correctness; a MISSING anchor silently loses matches.
#
# Name prefixes:
#   lex_   things the lexicon already catches (sanity: expect 0 in main)
#   fix_   the regexes proposed for flight.py in docs/leak-audit.md (so the
#          audit counts exactly what they would remove)
#   rt_    red-team terms the lexicon may miss (judge the hits by hand)
#   name_  aeronauts, experimenters and events (mostly common surnames: noisy)
#   idea_  the IDEA of human flight without technical vocabulary
#   mod_   post-1903 / modern leakage (not flight)
